# Dataset license records

- `pydicom-LICENSE.txt` is the license distributed with pydicom v3.0.1, which includes the versioned `CT_small.dcm` test file used here.
- `matplotlib-LICENSE.txt` is the license distributed with Matplotlib v3.9.2, which includes the versioned Jacksboro sample file used here.
- The Jacksboro elevation data originates from the NASA Shuttle Radar Topography Mission. NASA Earth science data are made openly available under the policy linked in `datasets/manifest.json`.

The manifest records exact source URLs and source hashes. These license records apply to the source fixtures only and do not change the license of TileStream code.
